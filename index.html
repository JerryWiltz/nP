Agentic nPort ​

Describe your circuit. Let your agent write the nP code. Give Codex, Claude or another coding assistant a typed request, existing code, or a scanned or hand-drawn schematic. It supplies the nP syntax and writes explicit, readable code with named components and connections.

Follow the Agentic nPort guide for environment setup, or choose the instructions below and save them as AGENTS.md in your working folder:

  • HTML agent: complete, minimal pages using an adjacent nP.js.
  • Obsidian agent: Markdown notes with npjs blocks for nPort RF Analysis.
  • Node.js agent: scripts using an installed nP package or a supplied module such as nP.cjs.
  • Website agent: nP code integrated into an existing site.

Supply the appropriate nP library and ask your coding assistant to read AGENTS.md. These instructions work outside this repository and need no repository checkout. Locally supplied nP files support offline analysis; the coding assistant has its own connection requirements. The agent writes code by default and runs it when asked. For HTML or website work, the site's browser bundle provides nP.js.

DC bias analysis ​

The current browser bundle includes nP.V() and network DC solving using the same nodal() or cascade connections as RF analysis. External capacitors open at DC, inductors short, and supported resistive paths remain. Call network.solveDC() when you want an explicit DC result.

For a supported network containing voltage supplies and NPN/PNP transistors, nP solves the external bias network before building its RF response. Read the returned network.operatingPoint for the solved state. Fixed-Q transistor construction remains available. Diode network DC adapters are not yet supported.

Start with the DC bias analysis guide. See the DC analysis details and active-device guide. Published npm and Obsidian builds have their own update schedules; use the APIs present in the bundle you supply.

Start here ​

Install the package in a Node.js or browser project:

sh
npm install @jerrywiltz/np

Import the named API in Node.js or an ESM browser application:

js
import * as nP from '@jerrywiltz/np';

The browser bundle is also available as dist/nP.js and exposes the global nP object. The project README contains a compact API overview and a complete circuit example.

Basic workflow ​

  1. Set nP.global.fList.
  2. Create components as n-port objects.
  3. Connect them with nP.nodal() or nP.cascade().
  4. Extract data with .out(...).
  5. Draw the network with nP.schematic(network).
  6. Display the result with nP.lineChart(), nP.lineTable(), or nP.smithChart().

The Schematics guide explains how the network's connections become a drawing, how to use its controls, and how to guide the layout of larger circuits.

Start with the Introduction, then follow the Tutorial for RF and digital signal examples. The RF Constructors page introduces the component families; Circuit examples shows complete RF networks. Physical-model design notes and equation provenance are maintained in the repository's developmentDocs/ directory.

For noise figure and output noise density, see Noise. For IP2, IP3, and harmonics, see Intermodulation.
