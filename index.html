Start here ​

Install the package in a Node.js or browser project:

sh
npm install @jerrywiltz/np

Import the named API in Node.js or an ESM browser application:

js
import * as nP from '@jerrywiltz/np';

The browser bundle is also available as dist/nP.js and exposes the global nP object. The project README contains a compact API overview and a complete circuit example.

Basic workflow ​

  1. Set nP.global.fList.
  2. Create components as n-port objects.
  3. Connect them with nP.nodal() or nP.cascade().
  4. Extract data with .out(...).
  5. Display the result with nP.lineChart(), nP.lineTable(), or nP.smithChart().

The API reference preserves the detailed constructor and function reference. Physical-model design notes and equation provenance are maintained in the repository's developmentDocs/ directory.
