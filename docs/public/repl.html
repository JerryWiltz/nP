nP RF REPL

Choose a starter example, edit the JavaScript, press Run, and inspect the result below.

Instructions

Each example runs in an isolated browser frame with the global nP object available.

  1. Choose an example.
  2. Modify the code.
  3. Press Run.
  4. Read the output or chart.

Set nP.global.fList before creating frequency-dependent circuits. Use nP.log(...) to print values.
