# Schottky diode records

`D({model: 'SMS7621'})` and `D({model: 'SMS7630'})` select the Skyworks
per-junction Schottky cards. They use the existing SPICE diode engine, its
temperature law, analytic current/charge derivatives, classical noise and
direct weak nonlinear sources. No separate `Schottky()` numerical constructor
or per-part constructor is introduced.

```js
nP.global.fList = nP.global.fGen(10e6, 3e9, 51);
var d1 = nP.D({model: 'SMS7630', qPoint: {vd: 0.05}, temperature: 300.15});
var dc = d1.ivTable({vd: {start: -0.1, stop: 0.35, points: 101}});
var rf = d1.out('s11dB', 's21dB');
nP.lineChart({inputTable: [dc], metricPrefix: 'none'});
nP.lineChart({inputTable: [rf], metricPrefix: 'giga'});
nP.schematic(d1);
```

Port 1 is the anode, port 2 the cathode. Voltage is anode minus cathode in
volts; current enters the anode in amperes. Defaults remain those of `D()`:
1N4148 when model is omitted, fixed `qPoint.vd = 0.6`, curve 0–0.8 V with
201 points, temperature `global.Temp`, frequency list `global.fList`.
Choose a lower fixed bias explicitly for a low-bias Schottky study.

## Source and boundaries

The source is [Skyworks 200041AH, June 13, 2024, Table 5, p.4](https://www.skyworksinc.com/-/media/SkyWorks/Documents/Products/201-300/Surface-Mount-Schottky-Diodes_200041AH.pdf).
Table 5 is explicitly per junction; package options and their inductances
appear separately in Table 1. Package suffixes such as `-079LF` are rejected
because no package-specific fit or inductance/capacitance network is supplied
by these records. Multi-diode packages require explicit separate junctions
and their supported external connections.

| Parameter | SMS7621 | SMS7630 | SI unit |
| --- | ---: | ---: | --- |
| IS | 4e-8 | 5e-6 | A |
| RS | 12 | 20 | Ω |
| N | 1.05 | 1.05 | dimensionless |
| TT | 1e-11 | 1e-11 | s |
| CJO | 1e-13 | 1.4e-13 | F |
| M | 0.35 | 0.40 | dimensionless |
| EG | 0.69 | 0.69 | eV |
| XTI | 2 | 2 | dimensionless |
| FC | 0.5 | 0.5 | dimensionless |
| BV | 3 | 2 | V |
| IBV | 1e-5 | 1e-4 | A |
| VJ | 0.51 | 0.34 | V |

The unlisted classical SPICE defaults are explicit: TNOM = 300.15 K (27 °C),
NBV = 1, KF = 0, AF = 1. The datasheet electrical specification tables use
25 °C; they do not define a different TNOM for the printed card. No external
leakage resistor is invented: `model.leakageResistance` is `Infinity`, while
the junction law retains its own reverse current and breakdown behavior.
The shared classical SPICE temperature behavior is not a measured thermal fit.

`D()` uses D reference designators and shows the selected model as its value.
It automatically selects its catalog-backed `schottky` symbol variant
from the record. The drawing-language `Schottky` name remains an artwork
alias; a label alone never selects numerical equations.

## Analysis and verification

An explicit `V()` supply in `nodal()`/`cascade()` selects external-network DC
before RF construction. Each solved placement rebuilds its own diode RF,
noise and nonlinear data without changing the reusable template or its curve
settings. Existing 1N4148 defaults and legacy diode behavior are unchanged.

The [tests](../../test/schottky.test.js) compare both records against independently
executed **ngspice 39.3** decks under [test/fixtures](../../test/fixtures/):
`schottky-sms7621.cir`, `schottky-sms7630.cir` and their `-noise.cir` decks.
They cover DC forward/reverse/breakdown, hot operation, all four complex S
entries at 10/100/1000 MHz, classical noise and resistor-fed external bias.
The [reference results](../../test/fixtures/schottky-reference.js) are simulator
outputs, not values generated by nP. Run decks in a temporary directory because
`wrdata` writes files. With the Norton port excitations used here, derive S
from `2*V/50`, subtracting one on the excited-port diagonal; NF uses the
input-referred noise spectrum squared divided by the SI `4*k*T*50` reference.
Tests allow 8e-7 absolute S-entry error and 2e-5 dB NF error, including physical
constant precision differences.

The [equation audit](../analysis/equationAudit.md) additionally checks each
card's current/charge derivatives through third order and explicit SI units.
Two-tone checks verify 20/30 dB product slopes per 10 dB equal-tone increase.
These checks validate the implementation of the printed card. They do not
establish measured detector sensitivity, package bandwidth, zero-bias/excess/
avalanche noise, compression or finite-power rectification. The shared
classical shot-noise approximation and direct-Taylor omissions in the
[diode contract](diodeModels.md) still apply.
